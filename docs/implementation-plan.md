# 구현 계획과 상태

## 기준과 현재 상태

dino-nest의 `aa0335e1864457f7f578256a6e177d0b6cb42dca` 커밋을 기준으로 공통 소스를 분리했습니다. 두 패키지의 초기 버전은 0.1.0이며 루트와 검증용 사이트는 private입니다. 원본 dino-nest 저장소의 소스나 미커밋 작업은 변경하지 않았습니다.

공개 API는 [설정 안내](./configuration.md), 저장소 경계는 [아키텍처](./architecture.md), 실행 명령은 [개발 안내](./development.md)에서 관리합니다. npm 범위 소유권 확인과 실제 공개, dino-nest 전환은 아직 남아 있습니다.

## 1. 공개 사용 방법 정의 — 완료

- [x] `createDinoConfig(siteConfig, presetOptions)`와 선택 기능의 기본값을 정의했습니다.
- [x] 객체 병합·배열 교체·추가 플러그인 유지 규칙을 구현했습니다.
- [x] `@theme/DinoOvum/...` 공개 컴포넌트 경로를 제공했습니다.
- [x] 기본 UI 번역과 사이트 문서 번역을 분리하고 사용자 메시지 재정의를 지원합니다.
- [x] 순수 계산 도우미를 `@dino-ovum/theme/utils`로 제공해 순환 의존성을 피했습니다.
- [x] PWA와 최근 업데이트 페이지를 선택 기능으로 두고 Agentation은 패키지에서 제외했습니다.

## 2. 패키지 개발 환경 구성 — 완료

- [x] pnpm workspace, preset, theme, 검증 사이트를 구성했습니다.
- [x] 공개 진입점·배포 파일·의존성·호환 범위를 선언했습니다.
- [x] Node.js `>=24.22.1 <25`, pnpm `10.5.2`, Docusaurus `3.10.1`, React `^19.0.0`을 사용합니다.
- [x] 개발·빌드·린트·테스트·압축·독립 설치 검증 명령을 제공합니다.
- [x] MIT 라이선스와 폰트 고지를 배포 파일에 포함합니다.

## 3. 공통 기능과 화면 분리 — 완료

## 4. 실제 배포물 검증 — 완료

- [x] 압축 파일의 진입점·버전 의존성·에셋·번역·라이선스 포함 여부 확인.
- [x] workspace 밖의 사이트에 두 압축 파일 설치 후 세 언어 빌드.
- [x] 프로덕션 브라우저에서 검색·탐색·최근 업데이트·언어 전환·반응형·테마 확인.
- [x] 하위 경로 배포의 PWA 메타데이터·아이콘·서비스 워커와 오프라인 동작 확인.
- [x] 사용자 문서·로고·사이트 이름·CSS·번역·컴포넌트 래퍼 적용 확인.
- [x] 임시 0.1.1 패키지 업그레이드로 공통 개선 전달과 사용자 파일 보존 확인.

**완료 기준:** 공통 소스를 복사하지 않고 패키지 버전 변경만으로 개선이 전달됩니다. 이 단계가 이번 패키지 구현의 기능 완료 지점입니다.

2026-11-10 검증: 린트, 단위 테스트 7개, workspace 및 독립 설치 사이트의 세 언어 프로덕션 빌드, 임시 0.1.1 업그레이드가 통과했습니다. 브라우저에서 검색 결과 이동·언어 전환·최근 업데이트 필터·390px 모바일 메뉴·테마 전환을 확인했습니다. `/handbook/` 서비스 워커가 제어하는 사용자 문서는 네트워크를 끈 상태에서도 새로고침됐으며 전송량은 0바이트였습니다.
